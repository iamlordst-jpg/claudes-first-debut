# Saiyan Legacy (Forge 1.20.1)

Dragon Ball inspired superpowers.

## Controls (rebindable under Controls > Saiyan Legacy)
- C  hold: charge ki (also slowly raises power level)
- Z  fire ki blast
- G  hold + release: Kamehameha (longer hold = bigger beam)
- X  power up (Base > Kaioken > Super Saiyan > Super Saiyan Blue)
- B  power down
- R  toggle flight
- V  instant blink

## Progression
- Killing mobs raises Power Level. Super Saiyan needs 2,500 PL, Blue needs 25,000 PL.
- Dragon Ball (N star) = Ender Eye + Gold Block + N Red Dye (shapeless).
- Collect all 7, right-click: +5000 PL (sneak: 10 Senzu Beans).
- Senzu Bean = Golden Carrot + Emerald + Glistering Melon (makes 2).
- Dragon Radar shows direction/distance to the nearest Dragon Ball.

## Build
Push to GitHub; the Actions workflow builds the jar (artifact: saiyanlegacy-jar).
